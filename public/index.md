## Now

Building two companies at once.

**LocalGhost.ai** is a local-first, privacy-by-architecture personal AI platform. Everything runs on hardware you own, in code you can audit, with no cloud dependency. It's past Phase 1, and the development box has captioned and indexed 30,408 photos and 2,573 videos without sending any of them anywhere.

**Anchor Terminal** grades the tools AI agents run on, from models and frameworks to data providers, scraping and payments. It runs the playbook behind the CryptoCompare exchange benchmark, co-founded with Quynh, who was the first CPO at CryptoCompare.

Writing the [Hard Truths](https://www.localghost.ai/hard-truths) series alongside both.

## LocalGhost.ai

The only cloud is you. A small silent box on your desk that runs the whole AI stack locally, with no subscription, no telemetry and no backdoor. If LocalGhost the company disappears, the box keeps working.

- Fully open source (MIT), every line auditable.
- Architecturally blind, the system prevents the company from seeing your data.
- Buy the hardware once, or build it from the open BOM.
- Ten Go daemons (ghost.noted, ghost.framed, ghost.voiced, ghost.tallyd, ghost.synthd, ghost.cued, ghost.mistd, ghost.shadowd, ghost.secd, ghost.watchd) own the control flow and call local models the way another daemon would call Postgres.
- Encrypted, sharded P2P backup via The Mist, with no central server to seize.

Links: [manifesto](https://www.localghost.ai/manifesto), [GitHub](https://github.com/LocalGhostDao), [Hard Truths](https://www.localghost.ai/hard-truths)

## Anchor Terminal

Grade them all. Anchor the one. Anchor Terminal grades everything agents run on from public evidence, has a panel of agents review it, and publishes the arithmetic.

- Listings graded AA to F from public evidence, score arithmetic public, every deduction sourced.
- Reviewed by a panel of agents, each on a different base model with a different focus (security, cost, and so on).
- Agent first. Every page has a Markdown twin.
- [letme.dev](https://letme.dev) picks the top-graded tool for a task.
- Rankings are never for sale. Audits are, for teams that want to know where agents get stuck on their product.

Links: [terminal](https://www.anchorterminal.com/), [llms.txt](https://www.anchorterminal.com/llms.txt), [for agents](https://www.anchorterminal.com/for-agents/), [get an audit](https://www.anchorterminal.com/audit/), [blog](https://www.anchorterminal.com/blog/)
